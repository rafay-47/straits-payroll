# 🎯 Quick Reference: Employee Management

## 🚀 How to Create Supervisor Account

### **In 5 Steps:**

```
1. Login: admin@company.com
2. Click: "Manage Employees" card on dashboard
3. Click: "+ Add Employee/Supervisor" button
4. Fill:
   ● Role: Supervisor
   Name: John Supervisor
   Email: john@company.com
   Password: super123
   Project: Construction Site A
5. Click: "Create Account"

✅ Done! Supervisor can now login to mobile app.
```

## 📊 Where to Find Everything

| What | Where |
|------|-------|
| Create Supervisor | Dashboard → Manage Employees → Add |
| Create Employee | Same location, select "Employee" role |
| View All Users | Manage Employees → "All Users" tab |
| View Supervisors | Manage Employees → "Supervisors" tab |
| View Employees | Manage Employees → "Employees" tab |
| View Pending | Manage Employees → "Pending" tab |
| Approve Employee | Click on pending employee, OR use existing approval screen |

---

## 🔑 Key Differences

|  | Supervisor | Employee |
|--|-----------|----------|
| Login | Email + Password | ID (0001) + PIN (1234) |
| Created By | Admin (Web) | Admin (Web) OR Supervisor (Mobile) |
| Needs Approval | No (instant) | Yes (after admin approval) |
| Can Login When | Immediately | After approval |

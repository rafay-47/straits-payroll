#### **Step 11: Check-In Validation**

**Before creating attendance record, system validates:**

```dart
// Validation checks
bool canCheckIn() {
  // Check 1: Is employee assigned to this project?
  if (!isAssigned) {
    return error('Not assigned to this project');
  }
  
  // Check 2: Already checked in to another project?
  if (hasActiveCheckIn()) {
    return error('Please check out from current project first');
  }
  
  // Check 3: Exceeded max check-ins for today?
  final todayCount = getTodayCheckInCount(projectId);
  if (todayCount >= maxCheckInsPerDay) {
    return error('Maximum check-ins reached (2/day)');
  }
  
  // Check 4: Device matches registered device?
  if (!deviceMatches()) {
    return error('Unauthorized device');
  }
  
  // All checks passed
  return true;
}
```

**Possible Scenarios:**

1. ✅ **Success:** All validations pass → Create attendance record
2. ❌ **Not Assigned:** "You are not assigned to this project"
3. ❌ **Already Checked In:** "Please check out from 'Office Building B' first"
4. ❌ **Max Check-Ins:** "You've already checked in twice to this project today"
5. ❌ **Wrong Device:** "This device is not authorized. Please contact your supervisor."

## 🔄 Complete User Flows Summary

### **Employee Journey:**
```
Download App → First Login (ID) → Device Binding → Create PIN 
→ Optional Biometric → Dashboard → Select Project 
→ Choose Check-In Method (GPS/NFC/QR) → Check-In Success 
→ Work → Check-Out → View History
```

### **Supervisor Journey:**
```
Login (Email/Password) → Dashboard → Add New Employee 
→ Fill Details → Upload Documents → Assign to Projects 
→ Employee Created (Pending) → Wait for Admin Approval 
→ Manual Check-In if needed → View Reports
```

### **Admin Journey (Web - Next):**
```
Web Login → Dashboard → View Pending Employees 
→ Review Details → Approve + Assign Custom ID 
→ Create Projects → Assign Supervisors 
→ Configure Check-In Methods → Approve Device Resets 
→ Generate Reports
```

## 🎯 Key Differences

| Feature | Employee | Supervisor |
|---------|----------|------------|
| **Login** | Employee ID + PIN | Email + Password |
| **Device Binding** | Required | Not required |
| **Primary Function** | Check-in/out | Manage employees |
| **Can Check-In** | Self only | Others (manual) |
| **Add Employees** | No | Yes (pending) |
| **Approve Employees** | No | No (admin only) |
| **Upload Documents** | No | Yes |
| **View Reports** | Own only | All assigned employees |
